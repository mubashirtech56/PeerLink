
# PeerLink AI Development Instructions

## Project Overview
PeerLink is a peer-to-peer chat and file transfer
application using TCP and UDP sockets.

## Before Starting Any Task

1. Read README.md.
2. Read docs/team-roles.md.
3. Check the current Git branch using:
   git branch --show-current
4. Ask the user:

   "Which team member are you?"

   Options:
   - Hamza
   - Hamid
   - Mubashir
   - Ibrahim
   - Taha

5. Ask:

   "What task are you working on today?"

6. Identify the task from the member's assigned
   responsibilities in docs/team-roles.md.

7. Confirm the task and relevant files before coding.

## Team Work Rules

- Do not modify another member's assigned module
  without permission.
- Do not overwrite another member's work.
- Do not change the project architecture without
  discussing it first.
- Use the existing folder structure.
- Keep code simple and readable.
- Do not add unnecessary libraries.
- Explain important changes.

## Git Rules

- Never commit directly to main.
- Never commit directly to develop.
- Work on the assigned feature branch.
- Do not switch branches without asking.
- Do not push or merge without permission.
- Do not modify unrelated files.

## Coding Workflow

Before coding:
1. Understand the task.
2. Inspect existing files.
3. Identify dependencies.
4. Explain the implementation plan.

After coding:
1. Test the changes.
2. Report modified files.
3. Explain what was implemented.
4. Mention any remaining issues.

## Important

If the task belongs to another team member,
tell the user before making changes.

Never assume which task the user wants.
Always ask first.
