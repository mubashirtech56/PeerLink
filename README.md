# PeerLink | Peer-to-Peer Chat & File Transfer System

PeerLink is a Computer Networks Lab project that implements a peer-to-peer communication system using raw TCP and UDP sockets. It supports real-time messaging and file transfers while exploring the behavior and performance of different transport protocols.

The project includes custom reliable UDP mechanisms such as Stop-and-Wait, Go-Back-N, and Selective Repeat, along with acknowledgements, sequence numbers, retransmissions, and flow control.

It also focuses on network performance analysis by measuring RTT, jitter, throughput, goodput, packet loss, and link utilization under different network conditions. Wireshark will be used to capture and analyze network traffic.

**Key Features:**
- TCP-based peer-to-peer chat and file transfer.
- Custom reliable UDP implementation.
- Stop-and-Wait, Go-Back-N, and Selective Repeat protocols.
- Peer discovery using UDP broadcast or multicast.
- NAT traversal using UDP hole punching.
- Network performance and link utilization analysis.
- Wireshark traffic capture and analysis.
